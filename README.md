# Greenside Market

A responsive grocery storefront built with React, JavaScript, HTML, and CSS using Vite.

## Run locally

```sh
npm install
npm run dev
```

Vite prints the local URL after the development server starts.

## Included

- Searchable grocery catalog with category filters
- Responsive product cards and favorites
- Basket drawer with quantity controls, subtotal, and free-delivery progress
- Mobile and desktop layouts

Product and hero photography load from Unsplash, so those images require an internet connection.
